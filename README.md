# Sakthi Dental Clinic Website

ShadowFox intermediate client project for **Sakthi Dental Clinic**, Hosur.

## Requirement understanding

The brief asked for a calm, professional healthcare site for patients of all ages — especially women, children, families, and seniors. Navigation had to stay simple, CTAs such as **Fix an Appointment** had to stay visible, and the layout had to work on phones first.

Pages map to the client brief:

| Page | Purpose |
| --- | --- |
| `index.html` | Hero, why choose us, core treatments, facilities, testimonials, founder teaser |
| `about.html` | Dr. Anupriya biography, vision & mission, full doctor panel |
| `treatments.html` | All 15 treatments with filter/search |
| `faqs.html` | 14 client FAQs as an accordion |
| `contact.html` | Lead form (left) + Reach us details and map (right) |
| `privacy-policy.html` | Client-provided privacy policy text |

## How the page is structured

1. Sticky nav with Home, About Us, Treatments, FAQs, Contact, plus a persistent appointment CTA.
2. Home leads visitors from trust (hero + assurance banner) into services, amenities, social proof, then booking.
3. Contact keeps the form on the left and clinic details on the right, stacking on mobile.
4. Footer repeats address, quick links, key treatments, and Instagram / Facebook / YouTube.

## How this supports usability

- Large type, ample whitespace, and lavender / white / pastel tones match the brief.
- Forms validate required fields and email format before submit.
- Appointment CTAs are buttons only (backend action left for the web team, as specified).
- Images use copyright-free Unsplash photos plus simple initials avatars for named doctors (clinic Drive assets can replace these).

Open `index.html` in a browser, or serve the folder locally.
